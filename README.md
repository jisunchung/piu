# PIU / **Frontend Developer, Designer**

## 프로젝트 소개

더 정교하고, 맞춤화된 AI 응답을 위해 사용자의 프롬프트를 단계별로 구조화할 수 있는 AI 멀티 비서 서비스

**제작연도 |** 2025년 7월 - 현재

**팀 구성 |** 개인 프로젝트

**기여도 |** 100%

**사용 스택 |** React, TypeScript, TailWind, Redux-Toolkit, Google GenAI, Supabase

**툴 |** Git, Figma

**프로젝트 문서 |** https://docs.google.com/document/d/1WHRoY6zJNgvPPYFi4Uwjd7xEnwlrTtUN64oMniuACDA/edit?tab=t.0

## 프로젝트 설계

https://docs.google.com/presentation/d/1767Wbu9uCBOE8HPj-pr_aLKgsXOB9FOZr4YcXjHngTE/edit

## 상세업무 및 성과

- useGemini 커스텀 훅으로 Google GenAI 연동 구현
- Flex, Button등 공유 컴포넌트 시스템 구축, SnapScrollArea, AutoSizeTextArea 등 UX 향상 컴포넌트 설계 및 적용
- 사용자가 텍스트 입력(Level1), 다중 입력 및 순서 변경(Level2), 스키마 정의(Level3)를 통해 점진적으로 복잡한 프롬프트를 구성하는 단계별 프롬프트 엔지니어링 UI/UX 구현 진행중
